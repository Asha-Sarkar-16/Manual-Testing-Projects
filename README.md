# Manual Testing Portfolio

## Project Overview

This repository contains manual testing artifacts created for practicing and demonstrating software testing skills. The project includes test cases, test scenarios, bug reporting samples, and supporting documentation for web application testing.

---

# Project Name

## Flipkart Login Module Testing

---

# Objective

To verify the functionality, usability, and validation behavior of the Flipkart login module using manual testing techniques.

---

# Scope of Testing

The following areas were tested:

* Login functionality
* Input field validation
* Password validation
* Error message handling
* Positive and negative scenarios
* UI behavior
* Browser compatibility basics

---

# Testing Types Used

* Functional Testing

* Smoke Testing
* Sanity Testing
* Negative Testing
* UI Testing
